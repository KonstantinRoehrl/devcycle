# Output discipline

The single owner of how every devcycle agent and skill reports. A skill, command, or
agent that needs this names this file and does not restate it.

> Report only what the caller needs in order to act. No preamble, no restatement of the
> brief, no narration of what you read or how you searched, no summary of your own process.
> Findings, deviations, and the required fields — nothing else. Silence on a point means you
> had nothing to report about it.

This is unconditional: the profile sizes the evidence tail, not the discipline.
